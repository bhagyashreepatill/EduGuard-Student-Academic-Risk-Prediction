# Application Screenshots & Visual Assets

This directory contains visual captures and screenshots of the **Student Academic Risk Early-Warning System (EduGuard)** dashboard across its core functional modules:

1. **`dashboard_overview.png`**: Cohort KPI cards, risk category distribution donut chart, and academic indicators summary bar chart.
2. **`student_risk_prediction.png`**: Interactive prediction interface with sliders, quick presets, gauge chart, score forecast, mathematical factor contributions, and tailored improvement steps.
3. **`student_records_table.png`**: Searchable and filterable student roster with risk badges and CSV export functionality.
4. **`data_visualizations.png`**: Bivariate scatter plots with trendlines, score histograms, and Pearson correlation heatmap.
5. **`model_performance.png`**: Test set evaluation metric cards (MAE, MSE, RMSE, R²), regression equation display, and actual-versus-predicted scatter plot.
6. **`intervention_guide.png`**: Three-tiered academic intervention protocol and domain-specific action steps for faculty.
